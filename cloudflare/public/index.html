Statistical limitations

Summary-level counts alone cannot support correlations, regressions, t-tests, ANOVA, or Cronbach's alpha. These require respondents' paired data.

The complete Python analysis backend remains separate and is not publicly hosted by this Cloudflare Worker. This edition includes a working browser-local data editor and frequency calculator.
